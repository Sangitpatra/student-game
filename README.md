# Tic Tac Toe Game

A fun and interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- ✨ Clean and modern UI with gradient background
- 🎮 Two-player gameplay (X and O)
- 📊 Score tracking for both players
- 🔄 Reset button to start a new game
- 📱 Fully responsive design (works on mobile and desktop)
- ⚡ Smooth animations and hover effects

## How to Play

1. Players take turns clicking on empty cells
2. Player X goes first
3. The first player to get 3 in a row (horizontally, vertically, or diagonally) wins
4. If all 9 cells are filled with no winner, the game is a draw
5. Click "Reset Game" to start a new round

## How to Deploy on Netlify

### Option 1: Drag & Drop (Easiest)
1. Go to [netlify.com](https://netlify.com)
2. Sign up or log in with your GitHub account
3. Drag and drop your project folder into Netlify
4. Your site will be live in seconds!

### Option 2: Connect GitHub Repo
1. Push this project to a GitHub repository
2. Go to [netlify.com](https://netlify.com) and click "New site from Git"
3. Select your GitHub repository
4. Click "Deploy site"
5. Netlify will automatically deploy whenever you push changes

### Option 3: Manual Deploy
1. Go to [netlify.com](https://netlify.com)
2. Click "New site from Git"
3. Authorize Netlify to access your GitHub
4. Select this repository
5. Leave build settings as default (no build command needed)
6. Click "Deploy site"
